# RaiseTech AWSコース 課題実践ポートフォリオ

このリポジトリは、RaiseTech AWSコースで学習した内容と、各課題の実践記録であり、私のスキルと学習成果を示すためのポートフォリオである。私は現職が非エンジニアの公務員であり、クラウドエンジニアへのキャリアチェンジを目指し、日々スキル習得に取り組んでいます。

## 自己紹介  
　私は専門職の公務員として誇りを持って仕事に取り組んでいますが、同時に自分のスキルが特定の組織の中でしか通用しないのではないか、という漠然として不安も感じていました。これからの時代を考えた時、業界や場所を問わずに価値を提供できる、普遍的な専門性を身に着けたい。そう考えたのがキャリアチェンジを目指した正直な理由です。  
　数ある技術分野の中でもクラウドを選んだのは、現代のITサービスに不可欠な土台であり、今後も間違いなく需要が伸び続ける領域だと確信したからです。また、私自身が、テクノロジー系の分野に興味関心があり、普段からAWSという言葉を目にしており、自分でAWSの無料利用枠を使ってEC2インスタンスを立ててPCから接続できた時、とてもワクワクしました。この、自らのスキルを高めたいという思いと、AWSに対するワクワク感が私のキャリアチェンジへの原動力です。  
　まずは、学んだ知識と技術を活かして、一日も早く現場で価値を出せるエンジニアになることが目標です。そして将来的には、技術力はもちろんのこと、現職で培った「ルールの意図を汲み取り、正確に実行する力」も活かして、顧客のビジネス要件を的確にインフラに落とし込める、信頼性の高いエンジニアになりたいと考えています。

## 最終成果物（課題１３）  
  
* 成果物  
[サンプルアプリケーション](https://github.com/yuta-ushijima/raisetech-live8-sample-app.git)の自動デプロイ  
  
* 仕組み  
CircleCIで以下項目を完全自動化デプロイ  
  * 簡易フロー  
    * cfn-lintでCloudFormationの構文チェック  
    * CloudformationでAWS環境構築  
    * AnsibleでRailsアプリケーションの構成管理  
    * Serverspecで自動テスト  
  * 具体的フロー  
    GitHubにプッシュすると、CircleCIのワークフローが自動的に開始されます。まず、`cfn-lint`でCloudFormationテンプレートの構文をチェックし、問題がなければCloudFormationスタックを作成してAWSインフラを構築します。次にAnsibleを実行して、EC2インスタンス上にRuby on Railsの実行環境をセットアップし、アプリケーションをデプロイします。最後にServerspecでサーバーの状態が期待通りであることをテストし、デプロイの正当性を保証します。

## 今後の学習方針  
RaiseTechでの学習を通じて、AWSを用いたインフラ構築と自動化の基礎を固めることができました。しかし、クラウド技術は日々進化しており、エンジニアとして継続的に学び続けることが不可欠だと考えています。  
そこで、今後は、以下の分野を中心にスキルを磨き、より技術力があり価値の高いエンジニアになることを目指します。  

1. Infrastructure as Code(IaC)  
  
Cloudformationの経験を土台に、現在多くの現場で採用されているTerraformを習得します。  
これにより、マルチクラウド環境にも対応できる、より再利用性の高いインフラ管理スキルを身に着けます。  

2. コンテナ技術  
  
EC2ベースのデプロイ経験からステップアップし、モダンなアプリケーション開発の主流であるコンテナ技術へ学習の幅を広げます。  
  * Dockerによるコンテナ化の基礎を固める。  
  * コンテナイメージを管理するECRの知識・技術を学ぶ。  
  * ECSやFargateを利用した、本番環境でのコンテナオーケストレーション技術を学ぶ。  

3. セキュリティとコスト最適化  
  
安全で効率的なインフラを設計・運用する能力を磨きます。  
  * WAFの導入やIAMのベストプラクティスなど、より実践的なセキュリティ対策を身につける。  
  * 常にコストを意識した設計・改善提案ができるスキルを身につける。  

4. 可観測性の向上  
  
システムの安定稼働にはデプロイ後の監視が不可欠です。そのために、CloudWatchの活用をさらに磨き、PrometheusやGrafanaといったオープンソースの監視ツールについても学習し、問題の早期発見と解決に繋がるアプローチを学びます。
